# aws-s3-static-website
Deployed a static website using Amazon S3 with public access configuration and bucket policies. Implemented static website hosting, optimized object permissions, and ensured high availability and durability using AWS-managed infrastructure.

Key Features

Amazon S3 static website hosting

Public access configuration & bucket policy

HTML/CSS static web content

Highly available and cost-effective deployment

Technologies Used

AWS S3, IAM, HTML, CSS
